# Sistema Educacional

O Sistema Educacional é uma aplicação desenvolvida em Java para gerenciar alunos, professores, disciplinas e turmas. O objetivo é facilitar a administração acadêmica, oferecendo um ambiente digital para acompanhamento do desempenho estudantil e organização das atividades escolares.

## Funcionalidades
- Cadastro e gerenciamento de alunos e professores 
- Registro de notas
- Controle de turmas

## Tecnologias utilizadas
- Java (Swing)
